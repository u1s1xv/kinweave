# KinWeave 家谱关系图

一款运行在安卓手机上的家族关系可视化应用。用网状关系图动态展示人物之间的关联，每个节点代表一个人，连线标注两人之间的关系。

> KinWeave = Kin（亲族）+ Weave（编织），寓意把家族成员编织成一张关系网。

## 功能特性

### 关系图管理
- 多关系图支持：可创建、切换、重命名、复制、删除多份独立的关系图，不同场景分别存储
- 关系图下拉切换：顶部下拉框一键切换，每份数据独立保存互不干扰

### 图形展示
- 动态网状关系图：节点自动布局，支持拖拽、缩放、居中和一键重新布局
- 多种布局方式：自动网状、树状（上→下 / 下→上 / 左→右 / 右→左），一键切换
- 位置锁定：手动调整好节点位置后可锁定，重排不会打乱布局
- 性别着色：男性蓝色节点、女性粉色节点，未设置灰色，一眼区分

### 人物管理
- 节点属性：姓名、性别、简介均可选，留空时显示为「未命名」
- 完整增删改查：点按节点可编辑或删除人物，点按连线可查看、修改或删除关系
- 搜索定位：输入姓名自动定位并高亮画布中的人物，视角自动居中

### 关系管理
- 关系标注：每条连线上显示关系名称，如父子、夫妻、兄弟、堂亲等
- 关系方向：有方向的关系连线带箭头（如父子，箭头由父指向子），无方向的对等关系不带箭头（如夫妻、兄弟）
- 常用关系预设：15 个常用关系标签一键填入，自动匹配方向
- 关系校验：自动拦截重复关系和自我连接

### 数据管理
- 撤销与重做：误删误改可一键恢复，最多回退 40 步，支持快捷键 Ctrl+Z / Ctrl+Y
- 本地持久化：所有修改自动保存到本机，关闭重开不丢失
- 数据备份：支持导出 JSON 文件备份全部关系图，也支持导入 JSON 恢复数据
- 旧数据兼容：自动迁移 v1/v2 旧版数据，已录入内容不会丢失
- 离线可用：无需联网，数据保存在每台设备本地

## 技术选型

| 用途 | 方案 | 说明 |
| --- | --- | --- |
| 图形引擎 | vis-network | 原生支持连线标注文字、自动布局、拖拽缩放与动态增删节点 |
| 应用形态 | HTML5 + JavaScript | 单页应用，数据以 JSON 模型组织 |
| 本地存储 | localStorage | 自动保存，无需额外依赖 |
| 安卓打包 | Capacitor 6 | 将网页应用封装为安卓原生 APK，离线运行 |

模块依赖顺序：core → graph / person / edge / history → render → ui → app

## 数据结构

应用数据以 JSON 格式组织，支持多份关系图：

```json
{
  "version": 3,
  "currentGraphId": "g-xxx",
  "graphs": [
    {
      "id": "g-xxx",
      "name": "我的家谱",
      "positions": {},
      "persons": [
        { "id": "p-xxx", "name": "张三", "bio": "简介内容", "gender": "男" }
      ],
      "edges": [
        { "id": "e-xxx", "from": "p-1", "to": "p-2", "label": "父子", "directed": true }
      ]
    }
  ]
}
```

- `persons`：人物节点，`name`、`bio`、`gender` 均为可选字段
- `edges`：关系连线，`label` 为显示在连线上的关系名称，`directed` 为 true 时连线带箭头
- `graphs`：多份关系图的集合，`currentGraphId` 指向当前选中的那份

## 本地开发

环境要求：Node.js 18 及以上。

```bash
# 安装依赖
npm install

# 直接在浏览器预览（用任意静态服务器指向 www 目录）
npx serve www
```

## 构建安卓安装包

环境要求：JDK 17、Android SDK（含 platform-tools、Android 34 平台与构建工具）。

```bash
# 同步网页资源到安卓工程
npx cap sync android

# 构建调试安装包
cd android
./gradlew assembleDebug
```

构建产物位于：

```
android/app/build/outputs/apk/debug/app-debug.apk
```

## 安装与使用

1. 将 `app-debug.apk` 传到安卓手机（微信、网盘或数据线均可）
2. 点击该文件安装，如系统提示「未知来源应用」，需在设置中允许该来源安装
3. 打开应用即可看到内置的示例家谱，可自行删除后录入自己的数据
4. 点击「＋人物」添加成员，点击「＋关系」连线并标注关系
5. 顶部下拉框可切换或新建关系图，底部状态栏显示当前人数与关系数
6. 点击「⋯」更多菜单可切换布局、锁定位置、导出导入数据

> 当前安装包为调试签名版本，适合个人安装使用；正式上架应用商店需改用正式签名。

## 数据说明

数据保存在每台设备本机，多设备之间不互通。如需多人共同维护同一份家谱，可通过导出/导入 JSON 文件手动同步，或后续接入云端存储。
